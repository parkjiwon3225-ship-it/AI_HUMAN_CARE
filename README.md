# AI_HUMAN_CARE — 독거노인 위험 감지·알림 시스템 (음성 파트 기록)

> 이 저장소는 **음성 파트의 진행 과정, 판단 기준, 실험 결과, 팀 공유 사항**을 시간순으로 기록한 곳입니다.
> 다른 팀원이 "무엇을, 왜, 어떤 근거로 결정했는지"를 처음부터 따라올 수 있게 쓰는 것이 목적입니다.
> 마지막 갱신: 2026-11-03 (작성 시점 기준, 이후 변경은 `docs/01_TIMELINE.md`에 이어서 기록)

## 한 줄 요약

위급 상황의 **음성**(도움 요청, 응급 상황 설명, 낙상 시 외침)을 라즈베리파이에서 실시간으로 감지하고,
감지되면 **앞뒤 약 10초의 오디오 클립을 앱으로 전달**하는 것이 목표입니다.
현재는 **마이크 도착 전 단계**로, 공개 데이터로 학습한 모델이 라즈베리파이4에서 실시간으로 돌아가는 것까지 확인했습니다.

| 아직 못 한 것 | **실제 마이크, 실제 집 환경, TV·라디오 오경보 검증** | 마이크 도착 후 |

## 가장 중요한 한계 3가지

1. **연기 데이터와 낭독 음성으로만 검증했습니다.** 실제 어르신의 차분한 도움 요청, TV 드라마 속 비명은 아직 모릅니다.
2. **짧은 외침(0.5~1초)과 소음이 큰 상황(SNR 0dB 이하)에서 재현율이 낮습니다.** (1초 약 0.7, 0dB 0.63)
3. **공사장 같은 큰 충격 소음에서 오경보가 늘었습니다** (v1: 17.1%). 후처리와 추가 학습이 필요합니다.
