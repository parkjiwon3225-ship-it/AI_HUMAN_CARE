# 04. 모델, 학습, 실험 결과와 해석

> 이미지 딥러닝 경험과 대응시켜 설명합니다. 지표의 정의는 [GLOSSARY](GLOSSARY.md).
> **모든 점수는 AI Hub 데이터(연기, 같은 태블릿)와 낭독 음성 기준입니다. 실제 마이크·실제 집 환경의 성능이 아닙니다.**

## 1. 소리를 이미지로 바꾸는 과정

| 단계 | 하는 일 | 이미지와의 대응 |
|---|---|---|
| 자르기 | 2.5초 = 40,000샘플 (16kHz) | random crop |
| STFT | 32ms 창을 10ms씩 밀며 주파수 성분 계산 (n_fft 512, hop 160) → 257 × 251 | 사진 한 장을 만드는 단계 |
| 멜 필터 | 257개 주파수를 사람 귀 척도 64개 대역으로 (50~8,000Hz) | 해상도를 줄이는 pooling |
| 로그 | 에너지에 log (+1e-6) | 감마 보정 |
| 표준화 | 창마다 평균 0, 표준편차 1로 (표본 표준편차) | 이미지별 정규화 |

결과는 **64 × 251의 흑백 이미지** (가로 시간, 세로 주파수). 말소리는 가로 줄무늬(배음)로 보입니다.

## 2. 모델

- 3×3 합성곱 → BatchNorm → ReLU → 2×2 MaxPool 블록 4개 (채널 16 → 32 → 64 → 64), 전역 평균 풀링, 드롭아웃 0.3, 선형 층(2개 출력: 정상, 위급).
- 파라미터 **60,530개**. 1샘플 순전파 약 **4,820만 MAC**. 라즈베리파이4 ONNX 파일 238.5KB.

### 연산량 비교 (이미지 대비)

| | 우리 오디오 모델 | 이미지(ResNet-50, 224×224) | 같은 구조를 1080p에 적용 |
|---|---|---|---|
| 입력 | 64×251×1 ≈ 1.6만 값 | 224×224×3 ≈ 15만 | 1920×1080×3 ≈ 620만 |
| 파라미터 | 6만 | 약 2,560만 | - |
| 1샘플 순전파 | 약 4,800만 MAC | 약 41억 MAC (약 85배) | 약 1,700억 MAC (약 3,500배, 화소 수 비례 어림값) |

- 이미지 쪽 숫자는 널리 알려진 대표값이고 1080p는 어림값입니다.
- **학습이 빠른 이유(추정)**: 입력·모델이 작고 에폭당 샘플이 약 2만 개. 오히려 GPU는 남고 **병목은 CPU의 데이터 가공**(소음 섞기, 자르기)일 가능성이 큼. (`nvidia-smi`로 확인 가능, 미확인)
- 샘플레이트를 올리는 것은 지금 병목이 아님([02 D05](02_DECISIONS.md)).

## 3. 학습 설정

| 항목 | 값 |
|---|---|
| 입력 | 위급 클립의 **실제 소리 구간**에서 2.5초(반복으로 채운 구간은 사용 안 함) |
| 양성(위급) 증강 | 60%는 정상 소음을 SNR 0~20dB로 얹음, 음량 ±12dB 무작위 |
| 음성(정상) | 정상 소음 무작위 2.5초(30%는 다른 소음을 섞음), v1은 절반을 일상 말소리(70%에 소음 섞음)로 대체 |
| 에폭당 균형 | 위급 = 정상 (같은 수) |
| 기타 | SpecAugment(주파수 8칸, 시간 25프레임), AdamW(lr 2e-3, wd 1e-2) + OneCycle, 배치 128, 20에폭 |
| 시간 (코랩 T4) | v0 337초, v1 298초 (v0 학습 데이터 약 2만 샘플/에폭) |

## 4. 지표 읽는 법 (요약)

- **재현율**: 위급 창 중 잡은 비율. **오경보율**: 정상 창 중 위급으로 울린 비율.
- **기준값**: 기본 0.5가 아니라 **"정상 소음 오경보 1%가 되는 값"**(v1은 0.882)에서 비교.
- **AUC**: 위급 창과 정상 창을 하나씩 뽑았을 때 위급이 더 높은 점수일 확률 (기준값과 무관한 순위 능력).
- `rec@1%amb`: 정상 소음 오경보 1%에서 위급 재현율, `rec@1%sp`: 일반 말소리 오경보 1%에서 위급 재현율.

## 5. 결과

### 5-1. v0 (정상에 말소리 없음) — 학습 직후 보고서

| 지표 | 값 |
|---|---|
| 검증 AUC (최고 에폭 18) | 0.993 |
| 재현율 / 오경보 (기준 0.5) | 0.962 / 3.2% |
| 1% 오경보에서 재현율 | 0.935 (기준값 0.882) |
| 클래스별 재현율 | 낙상 0.995, 도움요청 0.951, 응급의료 0.953 |
| 길이별 재현율 | 3.5초 미만 0.995, 3.5~4초 0.974, 4초 이상 0.937 |
| 정상 오경보 | 실내 2.2%, 실외 5.6% |

**해석**: 높지만 쉬운 문제(위급에는 말소리, 정상에는 없음). 에폭마다 오경보율이 0.7%~60.6%로 출렁인 것은 AUC는 안정적(0.97~0.99)인데 기준값 0.5의 위치가 흔들린 것 → **모델은 AUC로 고르고 기준값은 허용 오경보율에서 정한다**.

### 5-2. 탐침 시험 (평가 세트: 위급 1,500, 정상 소음 1,500, 처음 보는 화자의 낭독 744 + 소음 얹은 744)

| 시험 | v0 | v1 |

| 일반 말소리 오경보 (기준 0.5) | 94.5% | **2.7%** |
| 일반 말소리 오경보 (1% 기준값에서) | 87.9% | **0.9%** |
| 소음 얹은 말소리 오경보 (1% 기준값) | 89.1% | **1.7%** |

| 소음 구분 AUC | 0.993 | 0.990 |
| 위급 재현율 vs SNR 20 / 10 / 5 / 0 / -5 dB | 0.93 / 0.91 / 0.87 / 0.70 / 0.42 | 0.92 / 0.89 / 0.82 / 0.63 / 0.31 |

- 말소리가 창의 앞·가운데·뒤 어디에 있어도 재현율은 거의 같음(위치 무관).
- 조용한 입력에서 정상 오경보가 오르는 것은 창별 표준화가 작은 잡음을 키우기 때문(추정) → 실제 장비에서 **소리 크기 게이트**.

### 5-3. 대조 실험

| 실행 | 말소리 AUC | 위급 재현율(1% 정상 소음 기준) | 일반 말소리 오경보 | 학습에서 뺀 것의 재현율 |
|---|---|---|---|---|
| v0 | 0.848 | 0.941 | 0.879 | - |
| v1_speech | 0.998 | 0.931 | 0.009 | - |
| v0_phrase_holdout (문구 20% 제외) | 0.870 | 0.931 | 0.751 | 0.934 |
| v1_phrase_holdout | 0.997 | 0.926 | 0.011 | 0.927 |
| v1_senior_holdout (노인 클립 제외) | 0.998 | 0.927 | 0.005 | **0.937** |

**해석**
- 처음 보는 문구에서도 재현율이 같다 → **문구를 외우는 키워드 감지기가 아니다.**
- 노인 목소리를 학습에서 빼도 재현율이 유지된다 → 나이에 대한 일반화는 양호 (화자가 거의 겹치지 않아 신뢰도가 높은 시험).
- 문구 제외 시험은 같은 화자가 학습에 있을 수 있어서 화자 일반화는 증명하지 못한다.
- v1은 시드와 구성이 달라도 재현율이 약 0.93으로 안정적.

### 5-4. 상세 분석 (전체 Validation, 1% 정상 소음 오경보 기준값)

| 항목 | v0 (기준값 0.885, 재현율 0.935) | v1 (기준값 0.876, 재현율 0.926) |
|---|---|---|
| 오경보 많은 소음 | 공사장 9.9%, 공원 6.9%, 마트 4.1%, 음식점 3.3% | **공사장 17.1%**, 문 두드리는 소리 6.2%(n=32), 공원 4.6%, 마트 2.7% |
| 재현율 낮은 문구 | 경련 0.487, 갑자기 쓰러졌어요 0.600, 가슴 통증 0.634, 몸이 안움직여요 0.667, 살려주세요 0.686 | 경련 0.487, 가슴 통증 **0.561**, 갑자기 쓰러졌어요 0.578, 몸이 안움직여요 0.619, 손가락이 잘렸어요 0.675, 살려주세요 0.686 |
| 녹음 거리별 재현율 (원거리 / 근접 / 중간) | 0.788 / 0.851 / 0.960 | 0.767 / 0.818 / 0.956 |
| 장소별 재현율 (실내 / 실외) | 0.933 / 0.938 | 0.925 / 0.928 |

**해석 (가설, 확인 필요)**
1. 차분하게 상황을 설명하는 응급 문장이 v1에서 약해졌다 → 모델이 낭독과 구별하려고 **급박한 말투**를 단서로 쓰는 듯. 실제 어르신의 차분한 도움 요청에 약할 수 있음.
2. "살려주세요"가 0.686인 것은 이상 → 원거리/소음 클립에 몰렸는지 샘플을 들어 확인 필요(B1).
3. 근접 녹음(0.82)이 중간 거리(0.96)보다 낮은 것도 의외 → 찌그러짐 비율을 거리별로 재 볼 것(B1).
4. 공사장 소음(충격음, 큰 소리) 오경보 증가 → 큰 충격 소음을 정상에 더 넣고 오경보가 높은 샘플에 가중.

## 6. 종합 판단과 다음 모델(v2) 계획

**현재 판단**: v1이 말소리 지름길을 크게 줄였고 문구·연령 일반화도 양호하다. 그러나 **짧은 외침, 큰 소음, 차분한 응급 문장, 충격 소음 오경보**가 약점이고, 실제 마이크·TV·대화는 검증하지 못했다.

**v2 후보 (GPU 필요, 1회 약 5분)**
- 0.5~2.5초 길이의 말소리 조각을 소음 속 무작위 위치에 놓는 증강 (짧은 외침 대응)
- 공사장 등 큰 충격 소음을 정상으로 더 많이, 오경보가 높은 샘플에 가중
- 재현율이 낮은 문구·거리에 가중
- 정상 말소리에도 같은 방식으로 짧은 조각을 넣어 "짧은 말소리=위급" 지름길 방지

## 7. 파이4에서의 속도 (모델 238.5KB, ONNX)

| | 특징 추출(numpy) | 모델 | 합계 p95 | 0.5초 간격 여유 |
|---|---|---|---|---|
| 1스레드 | 8.2ms | 12.9ms | 21.3ms | 약 23배 |
| 2스레드 | 8.2ms | 7.5ms | 15.9ms | 약 31배 |
| 4스레드 | 8.2ms | 5.9ms | 14.4ms | 약 35배 |

- 0.5초마다 판단하면 코어 한 개의 약 4%, 0.1초마다 하면 약 21%. 마이크 녹음·클립 저장과 함께 돌려야 하므로 1~2스레드가 무난.
- 측정 중 온도 46.7 → 55.0°C, 성능 제한 `0x0`. 최종 장비 파이5는 더 빠르다.
- 학습 쪽 PyTorch와의 동일성: 특징 최대 차이 7.0e-06, 확률 최대 차이 2.1e-07.
