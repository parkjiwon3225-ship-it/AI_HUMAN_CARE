# 용어집

| 용어 | 쉬운 설명 |
|---|---|
| **샘플레이트(Hz)** | 1초에 소리를 몇 번 측정하는지. 16kHz면 1초에 16,000번. 말소리는 대부분 8kHz 아래라 16kHz로 충분 |
| **모노 / 스테레오** | 채널 1개 / 2개. 스테레오는 두 채널을 평균 내서 모노로 사용 |
| **STFT** | 짧은 구간(우리는 32ms)씩 밀며 주파수 성분을 계산하는 방법. 소리를 "시간 × 주파수" 표로 바꿈 |
| **멜 스펙트로그램** | STFT 결과를 사람 귀 척도(멜)의 대역(우리는 64개)으로 묶은 것. **소리를 이미지처럼 만든 것** |
| **로그멜** | 멜 스펙트로그램에 로그를 씌운 것. 모델의 입력 이미지 (64 × 251) |
| **dBFS** | 디지털 소리의 크기. 0이 최대, 작을수록 음수 (-24는 크고 -60은 아주 작음) |
| **SNR(dB)** | 말소리가 소음보다 얼마나 큰가. 0dB은 같은 크기, 20dB은 소음 진폭이 10분의 1 |
| **재현율(recall)** | 실제 위급 중 모델이 잡은 비율 |
| **오경보율(false alarm)** | 정상인데 위급이라고 울린 비율 |
| **기준값(threshold)** | 이 점수보다 높으면 위급이라고 판단하는 선. 높이면 오경보↓ 재현율↓ |
| **@1% 오경보 기준** | 정상 소음의 오경보가 1%가 되도록 기준값을 정한 상태. 모델끼리 공정하게 비교하는 방법 |
| **AUC** | 위급 창과 정상 창을 하나씩 뽑았을 때 위급이 더 높은 점수일 확률. 기준값과 무관한 순위 능력 (1에 가까울수록 좋음) |
| **지름길(shortcut)** | 모델이 진짜 목적(위급 말소리)이 아니라 쉬운 단서(말소리 유무, 음량, 패딩 등)로 푸는 것 |
| **탐침(probe) 시험** | 모델이 어떤 단서를 쓰는지 알아보려고 일부러 만든 입력으로 하는 시험 (말소리 길이·위치, 음량, 합성음 등) |
| **홀드아웃(holdout)** | 일부(문구, 연령 등)를 학습에서 빼 두고, 처음 보는 것에서도 되는지 확인하는 시험 |
| **SpecAugment** | 로그멜 이미지의 일부 줄을 가리는 증강 (이미지의 cutout과 비슷) |
| **증강(augmentation)** | 학습 데이터를 소음 얹기, 음량 바꾸기 등으로 다양하게 만드는 것 |
| **ONNX / onnxruntime** | 모델을 다른 환경(라즈베리파이)에서 돌릴 수 있게 저장하는 형식 / 그것을 실행하는 라이브러리 |
| **링 버퍼** | 최근 N초만 계속 덮어쓰며 들고 있는 메모리. 감지 순간의 "앞 10초"를 얻기 위해 사용 |
| **소리 크기 게이트** | 소리가 너무 작으면 판단을 건너뛰는 규칙 (조용한 방의 오경보 방지) |
| **연속 N회 감지** | 확률이 높은 판단이 연속으로 N번 나올 때만 경보 (순간 오경보 방지) |
| **컴퓨트 유닛** | 코랩 유료 플랜의 사용량 단위. GPU 종류에 따라 시간당 소모량이 다름 |
| **venv** | 프로젝트 전용 독립 파이썬 환경 |
| **SSH / scp** | 노트북에서 파이의 터미널을 원격으로 쓰는 방법 / 그 연결로 파일을 복사하는 명령 |
| **DHCP 예약** | 공유기에서 기기의 IP 주소를 고정하는 설정 |
| **RTC** | 전원이 꺼져도 시계를 유지하는 부품. 파이4에는 없어서 인터넷으로 시각을 맞춤 |
