## 4. 코랩 GPU 한도와 비용 (2026-11 조회 기준, 변동 가능)

- 무료 사용 한도는 **공개되지 않고 수시로 바뀐다.** 무료에서 GPU가 일시적으로 막힐 수 있고, 복구 시간은 정해져 있지 않다 (한 사례 약 18시간).
- 유료: **Pay As You Go $9.99 = 100 컴퓨트 유닛(일회 구매, 구독 아님, 유닛은 90일 후 만료)**, Pro는 월 $9.99(매달 100유닛). T4는 시간당 약 1.2~1.8유닛 → 100유닛은 약 57~84시간(자료마다 다름). 유료여도 특정 GPU가 보장되지는 않고, 유닛이 다 떨어지면 무료 수준으로 돌아간다.
- **판단**: 우리 학습은 1회 약 5분, 앞으로 GPU 총 2~3시간 예상이라 **지금은 불필요**. 마이크 도착 후 하루 안에 여러 번 재학습해야 하는데 무료가 안 잡히면 그때 **일회 구매**를 검토 (유닛이 90일 유효해서 나중에 사도 손해 없음).
- 학습이 빠른 이유는 모델과 입력이 작아서이며, GPU 사용률이 낮고 **CPU의 데이터 가공이 병목**일 가능성이 있다(추정). 더 빠른 GPU를 사도 속도는 별로 안 빨라질 수 있다.

### GPU 시간을 아끼는 방법
1. 다운로드, 변환, 진단은 CPU 런타임에서.
2. GPU는 학습할 때만 연결하고 끝나면 세션을 종료(`런타임 → 세션 연결 해제 및 삭제`).
3. 실험은 모아서 한 번에 실행. 결과가 드라이브에 즉시 저장되므로 끊겨도 이어서 가능.
4. 필수 실험(7b)을 먼저, 선택 실험(7c)은 시간이 남을 때.

## 5. 겪었던 문제와 해결

| 문제 | 해결 |
|---|---|
| 코드를 붙여 넣다가 약 10,300자에서 잘림 (`incomplete input`) | 셀을 5,000자 이하로 분할 |
| 압축 파일 다운로드가 불완전한데 완료된 줄 알았음 (`unexpected end of data`) | 서버 크기와 비교해 이어받기, 끊겨도 읽은 만큼 저장, 진행률 표시 |
| 학습 중 `float(loss)` 경고 | `loss.item()` 사용 |
| GPU 연결 실패 | CPU로 가능한 작업 먼저, 학습만 GPU |
| 런타임 재시작 시 변수 소실 | 셀 1부터 다시 실행 (드라이브 파일은 유지) |
